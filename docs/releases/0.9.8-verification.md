# 반도의 시간 0.9.8 검증 요약

## 변경 사항

- 소지금·교통카드 잔액·충전 절차를 제거했다. 개인 구매와 교통 탑승에 잔액 검사·차감이 없다. 예전 저장 파일을 읽기 위한 숨겨진 필드는 남아 있다. 도시 운영 자원·예산은 그대로다.
- 전국 역의 같은 역·다른 노선·양방향 승강장을 공용 대합실로 연결했다. 다음 역에서 하차하면 도착역의 노선과 출입구를 불러온다. 강남·서울역·홍대의 상세 지역에서 빠졌던 노선은 바닥 안내를 따라 전국 환승 장면으로 이어진다.
- 바닥에 노선색·노선명·방면·환승·출구 안내를 표시했다. 바닥 안내는 충돌체가 없어 보행을 막지 않는다.
- 실제 지도 출입구 좌표까지 계단·통로를 만들었다. 긴 통로에는 양방향 무빙워크가 있고, 다른 출구 계단을 가로지르던 벽·천장·바닥 충돌을 수정했다. 지하 경로 자체는 공통 모델에 맞춘 재구성이다.
- 열차 주행 4배·무빙워크 3배. 열차 30초·버스 50초 배차와 노선별 첫 도착 15초 분산, 정차·문 열림 시간은 유지한다.

- 강남 2호선은 공식 자료에 맞춰 B2·205m 상대식으로 바꾸고 양쪽 승강장별 계단·스폰·보행자 경로를 연결했다. 승강장 폭·계단 배치·절대 깊이는 추정이다.

## 자료 보완과 정확도

1,103개는 환승 중복과 계획역을 포함한 게임 역 ID 수다. 현실의 고유 역사 수와 같지 않다.

누락 8곳을 개별 조사해 6곳에 공개 건물 윤곽 417개 폴리곤 조각을 보완했다. 오수·반성은 각각 사진을 관찰해 추정 외관을 만들었다. 이제 1,103개 ID 모두 건물 표현이 있으며, 공개 건물 윤곽 보유는 1,101개다. 사진 참고 모델 2세트·7부품을 실제 건물 7채나 정밀 실측 복원으로 세지 않는다.

공식 역사 자료 34개 CSV와 안내 이미지 407개를 수집했다. 안내도는 356개 게임 ID에 연결된다. 원문 층 정보가 매칭되는 895개 ID는 정확성을 검증한 수가 아니다. 안내도 층을 직접 대조한 16개 실제 역·노선 키는 게임 22조합에 해당하며, 그중 CSV와 불일치하는 12조합을 따로 표시한다. 확인되지 않은 원문 층수를 3D 절대 깊이로 변환하지 않는다.

전국 모든 역을 현실과 똑같이 복원한 상태는 아니다. 대부분의 실내 평면·폭·높이·출구 연결 경로와 건물 외벽·미기재 높이는 공통 모델 또는 추정이다. 공개 안내도는 층과 시설 관계를 보여주지만 전체 실측 CAD를 제공하지 않는다. 실제 자료에서 확인한 부분과 게임용 재구성을 구분한다.

상세 근거·원본 출처·라이선스·미확인 항목은 전체 소스의 `AssetSources/STATION_PLANS_098.md`, `MISSING_STATIONS_098.md`, `STATION_AREAS_097.md`, `GIMPO_INTERNATIONAL_097.md`에 기록했다.

## 자동 검사

- GangnamLayout: 보행 구간 52개·이동 약 383m, 양방향 문 승하차 2쌍, 205m 양끝 바닥·중앙 선로·방면별 계단·신분당선 연결.
- NetworkTransfer: 306개 실제 보행 구간, 30개 문 승하차 쌍.
- DistrictTransfer: 30개 보행 구간, 바닥 글자 128개 크기·방향·충돌체 검사, 상세 지역에서 전국 교통망으로 승차 연결.
- NetworkMappedExit: 강남·성수·서면·양촌의 실제 지도 출구 32곳 왕복, 보행 모터 이동 약 13.9km.
- PlayerAccess: 과거 잔액 0·음수 저장 상태에서도 개찰구·상점·여가·버스·지하철·전국열차·KTX·체크인 이용. 문이 닫힌 차량은 여전히 탑승 불가.
- TransitSpeed: 차량 4종, 정차 시간 유지, 15초 첫 도착 분산, 긴 프레임에서도 정차역을 지나치지 않음, 무빙워크 경계.
- RuntimeUpdate: 21,600개 시각 표본과 시각 건너뛰기에서 차량·문 상태 비교.
- InternationalAirport: 17개 양방향 경로, 무빙워크 16개, 가장자리 보행 8회.
- AirportAccess: 3개 층 연결, 지하철→보안검색, 국내선 탑승교·기내 8곳, 직진 초과·복귀 24회.
- GimpoLayout: 23개 경로 왕복, 승차 방향 10개.
- Expansion: 지도 출구·지상/고가역 포함 16회 왕복, 대체된 옛 출구 통로 폐쇄·낙하 방지.
- StationArea: 전체 1,103개 ID·2,911개 타일 해독, 공식 길이 3곳과 보완 8곳의 실제 생성·도로 충돌·추정 모델 표시 검사.
- StationMinimap: 상세 강남 → 신분당선 → 도착역 하차 → 상세 지역 복귀 시 노선·출구·방면 표식 교체.
- RenderBudget: 정적 구조물 묶음, 차량·문 움직임, 숨겨진 차량 유지, 조명 수 제한 검사.
- WalkAccess·StationClearance: 상세 지역 보행 경로와 안내판·기둥 통행 여유 검사.

## 최종 실행 파일과 직접 플레이

macOS·Windows·Android 0.9.8 빌드 모두 오류 0건으로 완료했다. 위 자동 검사 16개도 모두 통과했다. Windows·Android는 실행 파일 생성까지 확인했으며 해당 기기에서 직접 플레이하지 않았다.

macOS 최종 실행본에서 김포공항 출입구 계단·무빙워크·자동 개찰구, 강남의 신분당선 환승·열차 탑승을 직접 조작했다. 첫 플레이에서는 신분당선으로 청계산입구까지 이동한 뒤 열린 문으로 걸어 내리고 도착역 환승 구조로 바뀌는 것을 확인했다. 서울역 환승 대합실, 강남 상대식 승강장, 오수·반성 외관도 살펴봤다.

직접 플레이에서 발견한 바닥 글자와 화살표 겹침, 하차 후 이전 노선이 남는 미니맵을 수정했다. 최종 빌드에서 바닥 글자가 가려지지 않는 모습과 신분당선으로 교체된 미니맵을 다시 확인했다. 각 기록은 `직접-플레이-확인/확인-장면.md`에 구분했다. 개인 잔액 0·음수에서 모든 구매·승차 조건은 PlayerAccess 자동 검사로 확인했다.

## 최종 성능 측정

Apple M5 (Mac17,2), 1440×900, 균형 설정, 60FPS 목표. 각 장면을 불러온 뒤 4초간 준비하고 6초씩 측정했다. 평균 FPS는 1,000 ÷ 평균 프레임 시간이다. P95는 프레임 시간의 95백분위수다.

10개 장면 평균은 각각 59.4–59.9FPS다. 처음 역을 바꾸며 모델을 만드는 순간의 지연은 이 안정화 후 측정에 포함하지 않는다. 직접 플레이에서도 지역 전환 초기에 잠시 프레임이 낮아졌다가 회복하는 현상을 관찰했다. 모든 기기와 해상도에서 끊김이 전혀 없음을 보장하는 결과는 아니다.

느린 기기에서는 화면 상단 품질을 `빠르게`로 바꾸고 창 크기를 줄이면 표시 거리·조명·그림자 부담을 낮출 수 있다. 현재 역의 필요한 구역만 생성하고 구조물 묶음, 구역별 표시 제어, 지도 타일 캐시를 적용했다. 원본은 `성능측정/098-1440x900.json`과 `검사기록-0.9.8/Performance.log`에 보관했다. 메모리 수치는 Unity가 보고한 할당량이며 전체 프로세스 사용량이 아니다. GC 계측의 -1은 측정 불가를 뜻한다.
